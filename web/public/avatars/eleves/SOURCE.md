# Avatars illustrés — Lycée Guergne La Renaissance

Les 40 illustrations statiques dans ce dossier sont des avatars **Open Peeps**, créés par **Pablo Stanley**, générés à partir du style Open Peeps de DiceBear.

- Œuvre / style : https://openpeeps.com/
- Générateur : https://www.dicebear.com/styles/open-peeps/
- Licence des illustrations : **Creative Commons CC0 1.0 (domaine public)**, utilisation personnelle et commerciale permise.
- Les fichiers sont copiés et hébergés **localement** dans le projet Guergne.
- Aucun nom, matricule, photo, identifiant de dossier ou autre donnée d'un élève n'a été transmis au service utilisé pour constituer le pack.
- Les illustrations sont de simples pictogrammes non représentatifs ; elles n'identifient pas réellement les élèves.
- Les photographies authentiques enregistrées dans l'établissement ont toujours priorité sur l'illustration.
- Attribution stable des illustrations dans `src/lib/avatar-eleve.ts`.

Pour régénérer le pack si nécessaire, exécuter `python3 scripts/generer-avatars-eleves.py` depuis `web/` dans un environnement disposant d'une connexion HTTPS.
